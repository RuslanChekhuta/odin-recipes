# Описание проекта Odin Recipes

## 1. Суть проекта
**Odin Recipes — это учебный веб-сайт с рецептами**, созданный в рамках базового курса (Foundations) программы The Odin Project. Проект представляет собой статичные веб-страницы, написанные исключительно на **HTML** без использования стилей (CSS). Его главная цель — закрепить навыки структурирования контента и работы с системой контроля версий Git.

## 2. Демонстрируемые знания и навыки
После завершения проекта я продемонстрирую следующие компетенции:

### Работа с Git и GitHub
* **Клонирование репозиториев:** умение клонировать уже созданный удаленный репозиторий с GitHub на локальный компьютер (`git clone`) вместо инициализации с нуля.
* **Фиксация и отправка изменений:** навык создания понятных коммитов (`git commit`) и синхронизации локального кода с удаленным репозиторием (`git push`).

### Структурирование HTML
* **Семантическая структура:** понимание и обязательное использование обязательных элементов документа, таких как `<!DOCTYPE html>`, тегов `<html>`, `<head>` (для метаданных) и `<body>` (для основного контента).
* **Базовый синтаксис HTML:** знание структуры HTML-документа, использование тегов заголовков (`<h1>`–`<h6>`) и параграфов (`<p>`).
* **Навигация и ссылки:** умение связывать страницы между собой с помощью относительных путей в тегах `<a>`.
* **Работа с контентом:** навык использования маркированных (`<ul>`) и нумерованных (`<ol>`) списков для ингредиентов и шагов, а также интеграция изображений с помощью тега `<img>` и обязательного атрибута `alt`.
